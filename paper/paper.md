# Summary

KairoECS is a Rust-first multi-method simulation engine that treats Discrete Event Simulation and Agent-Based Modeling as equal paradigms through a deterministic event-first kernel and ECS-style state model.

# Statement of need

Existing open-source simulation tools are often language-specific, paradigm-specific, or limited by host-language performance. KairoECS aims to provide a high-performance Rust core with idiomatic bindings and Arrow telemetry for scientific and operational workflows.
