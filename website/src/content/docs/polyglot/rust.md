---
title: Rust
description: Rust-first KairoECS entry point.
---

Rust owns the core runtime and deterministic contract surface.

- Core crates: `kairo-ecs-types`, `kairo-ecs-core`, `kairo-ecs-state`, and
  `kairo-ecs-rng`.
- Simulation crates: `kairo-ecs-des` and `kairo-ecs-abm`.
- Advanced crates: GPU, WebGPU, PDES, MPI, gRPC, streaming, and ML scaffolds.

Canonical source: `crates/README.md`.
