# `kairoecs new` Template Plan

## CLI template commands

```bash
kairoecs new factory-bottleneck --language python
kairoecs new mm1-queue --language rust
kairoecs new hybrid-ed-flow --language python
kairoecs new browser-flocking --language typescript
```

## Template structure

```text
my-model/
├── README.md
├── scenario.toml
├── seeds.toml
├── src/ or model.py
├── analysis/
├── outputs/.gitkeep
└── kairoecs.lock
```
