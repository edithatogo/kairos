# KairoECS: A multi-method simulation engine for DES and ABM

## Statement of need

KairoECS fills the gap between high-level simulation libraries that are easy to use but slow at scale and commercial multi-method tools that are powerful but not open-source.

## Summary

KairoECS provides a Rust-based deterministic simulation kernel with first-class support for Discrete Event Simulation and Agent-Based Modeling, Arrow telemetry, seed/replay manifests, and bindings for Python, R, Julia, TypeScript, C#, and Go.
