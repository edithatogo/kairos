# Notion Project Page Template: KairoECS

## Mission

KairoECS is a next-generation, open-source, Rust-first simulation engine treating DES and ABM as equal paradigms.

## Current phase

Conductor setup and track planning.

## Key decisions

- Rust core.
- Event-first scheduler.
- ECS-style state model.
- Stable C ABI with UniFFI/Diplomat where useful.
- Apache Arrow telemetry.
- Python 3.10-3.14.
- C# .NET 10-11.
- Docusaurus docs on GitHub Pages.
- Contract-first subagent workflow.
