# Maintainer Ladder

1. Contributor: submits issues, docs, examples, or code.
2. Regular contributor: repeated high-quality work.
3. Reviewer: trusted to review a subsystem.
4. Area maintainer: owns a package/track.
5. Release manager: coordinates releases.
6. Steering member: helps resolve project-wide direction.

Promotion is based on judgment, care, reliability, and communication, not commit count alone.
