# KairoECS Roadmap

## v0.1 alpha

- Rust `kairo-ecs-core` scheduler
- `kairo-ecs-state` minimal entity storage
- stable C ABI preview
- Python preview binding
- Arrow event log preview
- docs site skeleton
- DES, ABM, hybrid examples

## v0.2

- broader FFI coverage
- experiment runner prototype
- benchmark harness
- R/Julia/TypeScript preview scaffolds

## v0.3

- C#/Go preview scaffolds
- model zoo expansion
- OpenSSF and supply-chain maturity gates
- cloud accelerator smoke routes for Google Cloud TPU, AWS Trainium/Inferentia, and Azure GPU/Batch trial-credit validation

## v1.0

- stable scheduler semantics
- stable C ABI v1
- versioned Arrow schemas
- conformance suite across published languages
- documented compatibility promises
- clarified hardware-backed validation paths for GPU, TPU, and other accelerator routes
