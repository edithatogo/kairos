# Open Game Theory Ontology

This subrepository contains the semantic source fixtures for Kairos game theory execution.

Current scope is deliberately narrow and auditable:

- normal-form game concepts,
- extensive-form game concepts,
- Turtle and JSON-LD source fixtures,
- provenance records for externally generated research schemas,
- deterministic generated Rust component inputs.

Runtime claims are owned by downstream Kairos tracks and require checked evidence manifests.
