# Contributor Onboarding

Welcome to KairoECS. The fastest way to contribute is to pick work that has a clear track, owner, and test expectation.

## First contribution path

1. Read `README.md` and `conductor/track-map.md`.
2. Pick an issue labelled `good first issue` or `kind:docs`.
3. Create a branch named `subagent/<name>/<task>` or `track/<nn>-<slug>`.
4. Run the relevant local checks.
5. Fill in the PR template.
6. Update any affected `handoff.md`.
