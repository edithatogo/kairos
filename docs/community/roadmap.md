# Public Roadmap

```text
Stage 0 — Foundation: naming, governance, CI, core contracts.
Stage 1 — First useful engine: deterministic scheduler, minimal ECS, seed/replay skeleton.
Stage 2 — First user-facing package: Python 3.10-3.14 preview, Arrow event logs, examples.
Stage 3 — Multi-language previews: TypeScript/Wasm, R, Julia, C#, Go.
Stage 4 — Public beta: OpenSSF trust gates, model zoo, compatibility table.
Stage 5 — 1.0: stable C ABI, stable telemetry schemas, selected stable APIs.
```
