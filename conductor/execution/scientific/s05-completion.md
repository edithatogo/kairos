# S05 Sobol sampling and sensitivity

`kairo-ecs-cli::ensemble::SobolSequence` uses unscrambled Joe–Kuo D(6) direction numbers for dimensions 1–16 and 32-bit Gray-code points. Random access and streaming address the same half-open index range [0, 2^32). `LegacySobolSequence` preserves the old multiplier directions for replay. Test exact uint32 coordinates from a versioned [SciPy Sobol](https://docs.scipy.org/doc/scipy-1.18.0/reference/generated/scipy.stats.qmc.Sobol.html) reference, including the last point and exhaustion.

For global sensitivity, draw independent uniformly distributed A/B row pairs, and swap one coordinate at a time. Use Jansen squared differences divided by twice the pooled A/B variance to estimate first-order and total effects. Resample complete paired rows for 199 percentile bootstrap replicates. This preserves the dependence between each pair and its hybrids. Return 95% intervals for both indices with no truncation at zero or one. Return an error for invalid dimensions, budget, non-finite outputs, or undefined variance. The sampling and bootstrap seeds are independent and reductions run in fixed row order. See [Jansen (1999)](https://doi.org/10.1016/S0010-4655(98)00154-4).

Compare against the analytical Ishigami and Sobol-G variances over 40 fixed independent seeds, 1,024 pairs per seed. Require absolute mean bias at most 0.025, root-mean-square error at most 0.085, and at least 33 of 40 intervals containing each true index. These are finite-fixture regression criteria for approximate marginal coverage, with no simultaneous coverage guarantee.
