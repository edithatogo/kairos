# Owned execution and retirement: exact public API draft

Status: proposed for joint review, 4 October 2026; not dispatch authority. This appendix and [the behavioral contract](owned-handler-retirement-leaf.md) must be accepted/frozen together. No standalone API slice satisfies the whole joined behavior.

## Public inspection/API proposal

Opaque types below have private fields, Clone/Debug, no public constructor, serde, Ord/Hash or mutable access. NativeTransitionId additionally has Eq/PartialEq and runtime_id()->u64, recovery_generation()->u64, sequence()->u64. Private construction binds actual issuer identity and checked sequence. NativeIntentKind is Copy/Debug/Eq/PartialEq {Present,Absent}. NativeIntentView getters: id()->&NativeTransitionId; source_lp()->LpId; authority()->OptimisticAuthority; logical_id()->&LogicalEventId; kind()->NativeIntentKind; message()->Option<&OptimisticMessage>; predecessor()->Option<&NativeTransitionId>; retirement_dependencies()->&[NativeTransitionId]; is_current()->bool; retirement_request()->Option<&NativeRetirementRequest>. Dependencies are exact currently unresolved ancestor cancellations in stable private ID order. Absent message is None; it never mints a positive ticket.

NativeRetirementRequest getters: transition_id()->&NativeTransitionId; predecessor_positive()->&OptimisticMessage; predecessor_anti()->&OptimisticMessage; sender()->&NativeAccountingAuthority; old_receiver()->&NativeAccountingAuthority. NativeRetirementCapability exposes the same getters plus recorded_revision()->u64 and applied_effect()->NativeRetirementEffect. Effect enum is Copy/Debug/Eq/PartialEq {TombstonedAbsent,RemovedPending,RolledBackExecuted}; duplicate readback retains its original effect/revision. NativeOutboundSend adds retirement_request()->Option<&NativeRetirementRequest>, Some for every issued anti and None for positives. OptimisticOutboundView adds intent_id()->&NativeTransitionId and retirement_dependencies()->&[NativeTransitionId]; existing statuses retain real Ready/BlockedReplacement/RetiredPredecessorAwaitingAccounting meaning.

native_intents(&self) -> Result<Vec<NativeIntentView>, OptimisticError>;

Pollers stay live/sealed-gated and observational; polling never consumes work. Pending request polling returns only unresolved source cancellation requests, including self, in stable private ID order; retained completed requests remain inspectable through native_intents but are excluded from pending polling. Existing run_until_with_budget delegates owned mode to the detailed API and maps failure to its cause; document that earlier committed steps survive and callers needing failure progress must use the detailed API. Legacy behavior is unchanged. Raw receive still cannot forge Scoped native admission; raw owned fossil_collect stays NativeGroupCutRequired. Legitimate owned run no longer returns OwnedRuntimeJoinIncomplete.

OptimisticOwnedStep is an opaque Clone/Debug inspection with kind()->OptimisticOwnedStepKind; selected()->&[OptimisticMessage]; lp_id()->Option<LpId>; trigger_key()->Option<&OptimisticEventOrderKey>. Copy/Debug/Eq/PartialEq kind variants PositiveRound,Anti,Rollback. PositiveRound lists exact selected envelopes in LP order, with lp_id/trigger_key None. Anti and Rollback each list exactly their one full triggering envelope in selected(), with lp_id Some(destination) and trigger_key Some(its complete order key). Executed-positive anti suffix rollback remains one Anti unit; Rollback means positive-straggler control only. No nested/double-charged step. No invented extra execution. OptimisticOwnedFailurePhase is Copy/Debug/Eq/PartialEq {PreCallbackRejected,Compensated,PoisonedBeforePublication,CommittedCleanupFailed}. OptimisticOwnedRunFailure is opaque Clone/Debug with cause()->&OptimisticError; trigger_cause()->Option<&OptimisticError>; progress()->&OptimisticRunProgress; phase()->OptimisticOwnedFailurePhase; attempted()->&[OptimisticOwnedStep]; compensated_lps()->&[LpId]; invalidated_lps()->&[LpId]; poisoned()->bool. Implement Display/Error. On fatal compensation/cleanup failure, cause is the fatal restore/clone/Drop/own-gate cause and trigger_cause preserves the original rejection when distinct; without a later fatal failure cause is the original rejection and trigger_cause is None. First fatal cause follows deterministic LP/cleanup order; phase/poison status never presents it as healthy compensation. Poison invalidates every runtime token, including untouched LPs, via the poison predicate without epoch wrap; invalidated_lps lists all owned LPs when poisoned. Progress retains exact consumed budget, prior committed observer messages and current queue/replay counts; never publish staged copies as committed. Observer copies can include genuinely committed retained blocked versions; only ready_native_sends issues deliverable tickets. Outboxes are authoritative remote obligations. attempted describes the failed/current unit only (bounded by selected LP count), while progress aggregates this run's actual earlier committed units. For CommittedCleanupFailed, progress additionally includes the current unit's already committed observer messages, resulting pending counts and consumed budget; attempted still identifies that unit. For PreCallbackRejected, Compensated and PoisonedBeforePublication, current staged messages remain excluded from progress.

OptimisticNativeCleanupFailure is opaque Clone/Debug: runtime_id()->u64; lp_id()->Option<LpId>; cause()->&OptimisticError. OptimisticNativeCutReport is opaque Clone/Debug: committed_gvt()->Tick; reports()->&[OptimisticFossilReport]; cleanup_failures()->&[OptimisticNativeCleanupFailure]. Reports are in participant runtime-ID order. OptimisticNativeCutFailure is opaque Clone/Debug with cause()->&OptimisticError; failed_runtime_id()->Option<u64>; poisoned_participants()->&[u64]; Display/Error.

Add OptimisticError variants SnapshotClonePanicked(LpId), SnapshotDropPanicked(LpId), NativeTransitionIdentityExhausted{runtime_id:u64}, UnknownNativeTransition, ConflictingNativeTransition, NativeTransitionFork, NativeTransitionCycle, NativeTransitionDependencyMissing, NativeGroupParticipantDuplicate{runtime_id:u64}, NativeGroupCoverageIncomplete{missing:Vec<LpId>,unexpected:Vec<LpId>}, NativeGroupIssuerMismatch{participant_runtime_id:u64,expected_runtime_id:u64,actual_runtime_id:u64}, NativeGroupInputsOpen{runtime_id:u64}. Retain existing errors for actors, authority, routes, all capacities, revision/incarnation/epoch, GVT and callback restore/handler failures. Additive alpha enum expansion is intentional; do not add Ord/Hash to public authority.

Extend accounting_snapshot with source_intent_count()->usize, receiver_retirement_count()->usize and reserved_tombstone_count()->usize and reserved_pending_count()->usize. Existing blocked_count includes retained blocked local and remote positives. Existing reserved_receipt_count counts reserved-but-not-materialized unique slots; retained_receipt_count counts actual retained records, with shared records once. Existing retirement_count includes unresolved source cancellations and receiver requests not applied, with local shared roles once. minimum_obligation_tick includes local queues/replay, all remote/blocked positives/antis, incomplete retirement and required ancestors. completed proofs impose retention, not fictitious runnable work. No global/durable cut claim comes from sampling a snapshot.
