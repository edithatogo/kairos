# Track 61 Risk Register

Severity scoring scale: Low/Medium/High/Critical = 1-4. Low = bounded documentation or local workflow inconvenience; Medium = delayed phase closeout or limited user-facing claim risk; High = broken implementation, release-blocking evidence gap, or unsafe public claim; Critical = data race, unsafe memory behavior, credential exposure, or knowingly false release/parity claim.

| Risk | Impact | Mitigation |
|---|---|---|
| Cycles or malformed graph relations enter solver | Infinite traversal or invalid result | Cycle detection and malformed topology fixtures. |
| Extensive-form solver diverges from normal-form ontology | Split APIs | Certification requires shared generated component contracts. |
| Final certification is only local | False release confidence | Require pushed ref and GitHub Actions review. |
