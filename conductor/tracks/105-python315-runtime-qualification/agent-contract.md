# Ownership

This chat owns candidate reconciliation and coordinated Python migration. Planning registration is separate from runtime write authority. Use the single-maintainer harness: isolated worktree, narrow path claim, bounded hashed context, scope check and one commit per claim. Preserve active writers, private history and runtime pins. Do not take over an expired lease or replace a running environment. Shared Python, binding, CI and release owners retain their contracts. No email or native configuration changes.
