# Risk Register: Track 37 ML/AI Integration & Inference

| Risk | L | I | Sev | Mitigation | Owner | Escalation trigger |
|---|---|---|---|---|---|---|
| ML model staleness: trained model diverges from evolving simulation semantics | 4 | 4 | 16 | Version models alongside simulation schemas; require model hash in scenario manifest; fail CI if model version does not match domain version | ml-integration-agent | Model hash mismatch detected during simulation init |
| Inference latency spikes cause tick deadline misses | 3 | 5 | 15 | Enforce per-tick inference timeout; provide async inference mode for non-blocking models; benchmark latency under varying batch sizes | ml-integration-agent | Any tick exceeds latency budget by >2x in benchmark |
| ONNX Runtime version incompatibility with model IR version | 4 | 3 | 12 | Document supported ONNX opset and IR versions; CI matrix tests multiple ONNX Runtime versions; provide model conversion utility | ml-integration-agent | ONNX Runtime fails to load model with error not in known-compatibility list |
| GPU memory contention with Track 32 compute work | 3 | 4 | 12 | Shared GPU memory arena with explicit budget; mutex-guarded device context; priority queue for inference vs compute work | gpu-agent | OOM during concurrent inference and compute |
| Training-serving skew for neural surrogates | 4 | 4 | 16 | Validate surrogate output against original system on every CI run; enforce accuracy threshold (5% relative error); flag regressions before release | ml-integration-agent | Surrogate accuracy drops below threshold on any CI run |
| Gymnasium API version drift (gymnasium package updates break kairo_gym) | 3 | 3 | 9 | Pin gymnasium version range in setup.cfg; run integration test against latest stable gymnasium on CI; test pre-release gymnasium in allowed-failure mode | ml-integration-agent | Breaking gymnasium release without kairo_gym compatibility patch |
| Feature-flag combination explosion (onnx+tensorrt+burn+gymnasium matrix) | 3 | 3 | 9 | CI matrix limited to supported combinations; document unsupported combinations explicitly; use cargo-hack to verify each feature compiles in isolation | ci-agent | Compilation failure in any documented-supported feature combination |
| ONNX Runtime shared library not found at runtime | 4 | 3 | 12 | Provide clear error message with platform-specific install instructions; document LD_LIBRARY_PATH/DYLD_LIBRARY_PATH/PATH requirements; cargo feature `onnx` auto-detects via pkg-config | ml-integration-agent | User report of "onnx feature enabled but library not found" without resolution path |
