# Risk Register: Track 35 Distributed Simulation (MPI/gRPC)

Severity scale: Likelihood 1-5 x Impact 1-5. Low 1-4, Medium 5-9, High 10-16, Critical 17-25.

| Risk | Likelihood | Impact | Severity | Mitigation | Owner | Escalation trigger |
|---|---|---|---|---|---|---|
| Network latency causes GVT stall — conservative PDES performance collapses when message round-trip exceeds lookahead window | 4 | 4 | 16 | gRPC mode with configurable timeouts and adaptive batching; MPI mode for low-latency networks; document latency budget per LP count | distributed-agent | GVT fails to advance for > 100 consecutive ticks under representative load |
| Node failure causes partial simulation state corruption — entities on failed node are lost without recovery | 3 | 5 | 15 | gRPC fault tolerance: coordinator heartbeat, worker removal, entity reassignment or scope reduction; local heartbeat classifier now distinguishes healthy/suspect/failed workers; at-most-once migration with idempotent apply | distributed-agent | Fault tolerance test fails — simulation crashes on worker failure |
| Split-brain: network partition causes two sub-simulations to diverge | 2 | 5 | 10 | Coordinator-based membership with quorum; minority partition halts; gRPC health checks with configurable partition detection timeout | distributed-agent | Two sub-simulations produce conflicting final states for the same entity |
| Serialization overhead dominates — entity migration or event exchange marshalling exceeds simulation compute time | 3 | 3 | 9 | Use compact binary serialization (bincode for internal, protobuf for gRPC); benchmark serialization overhead per message size; zero-copy where possible (Arrow IPC) | distributed-agent | Serialization + deserialization > 20% of total simulation time |
| MPI library availability — `rsmpi` requires system `libmpi` which varies across platforms and HPC environments | 3 | 4 | 12 | MPI mode gated behind `mpi` feature flag; CI tests use mock MPI or containerized MPI; document MPI installation per platform (OpenMPI, MPICH, MS-MPI) | distributed-agent | `crates/kairo-ecs-mpi/` fails to build on any Tier 1 platform |
| Entity migration during active event processing causes race conditions — destination LP processes events for entity before migration completes | 2 | 5 | 10 | Migration handshake with coordinator acknowledgment; entity is paused at source LP during migration; destination LP only schedules events post-acknowledgment; local MPI/gRPC validators reject self-migration, blank IDs, missing components, and empty component payloads | distributed-agent | Entity migration test fails — component state divergence after migration |
| gRPC service discovery complexity — hardcoded peer addresses break in dynamic cloud environments | 3 | 3 | 9 | Support static peer configuration initially; provide DNS-based discovery as configurable option; local peer validator rejects duplicate/self peers and malformed endpoint schemes; document integration points for external service discovery (Consul, Kubernetes DNS) | distributed-agent | gRPC mode fails to establish peer connections in containerized test |
| Distributed telemetry batch ordering mismatch — Arrow record batches from different nodes arrive out of order and produce inconsistent merged views | 3 | 3 | 9 | Tag batches with node ID and tick range; local telemetry validators reject empty payloads and invalid tick ranges; sort before merge; document that global ordering is not guaranteed across nodes | distributed-agent | Distributed telemetry merge gate fails on content equality check |
| MPI deadlock on collective operations — mismatched `MPI_Send`/`MPI_Recv` or `MPI_Allreduce` call patterns across ranks | 2 | 5 | 10 | Strict ordering of MPI calls per tick phase; local rank validator rejects duplicate ranks/LPs before startup; deadlock detection via MPI timeout (`MPI_Iprobe`); unit-test communication patterns with mock MPI | distributed-agent | MPI test hangs indefinitely on any collective operation |
