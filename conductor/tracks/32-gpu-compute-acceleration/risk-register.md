# Risk Register: Track 32 GPU Compute Acceleration

| Risk | L | I | Sev | Mitigation | Owner | Escalation trigger |
|---|---|---|---|---|---|---|
| Platform fragmentation — Metal (Apple), CUDA (NVIDIA), Vulkan (Linux/Windows) have different shader semantics, workgroup limits, and memory models | 5 | 4 | 20 | Use wgpu as the cross-platform abstraction layer; maintain separate backend modules per API; parity tests must pass on every supported backend before release | gpu-compute-agent | Any backend fails parity test on its target platform |
| GPU memory overhead — large world states (10M+ entities) exhaust VRAM on consumer GPUs or integrated graphics | 4 | 4 | 16 | Implement streaming buffer management (tiled upload/download); measure memory per entity type and publish budget guidance; add `gpu-memory-budget` gate | gpu-compute-agent | 10M-entity scenario exceeds 1 GB VRAM on any tested GPU |
| Nondeterministic scheduling on GPU — workgroup execution order is undefined, causing divergent output from CPU when event ordering matters | 4 | 3 | 12 | Document scheduling nondeterminism in `docs/gpu-compute/event-ordering.md`; for DES dispatch, use multi-pass sorting with atomic operations to enforce partial ordering; parity test covers fixed-seed deterministic scenarios only | gpu-compute-agent | Parity test fails with same seed on same GPU across two consecutive runs |
| Hardware diversity — CI has no GPU hardware; all GPU testing must be done on developer machines or self-hosted runners | 4 | 3 | 12 | Separate CI into CPU-only (always runs, covers compilation and feature isolation) and GPU (runs on self-hosted runners with GPU); fall back to informational-only gates when no GPU is present | gpu-compute-agent | GPU gate fails on self-hosted runner for a merged PR |
| Integration breaks CPU determinism — adding GPU support accidentally changes CPU code paths, shared data structures, or random number seeding | 3 | 5 | 15 | All GPU code lives behind `#[cfg(feature = "gpu")]`; no shared mutable state between CPU and GPU paths; CPU-only regression suite must pass identically with and without the `gpu` feature enabled | gpu-compute-agent | CPU-only benchmark regression test fails after GPU feature merge |
| WGSL shader compilation breaks on wgpu version upgrade | 3 | 3 | 9 | Pin wgpu version in `Cargo.toml`; document known-good shader compilation targets; run shader compilation as part of `gpu-crate-compiles` gate | gpu-compute-agent | WGSL shader fails to compile on latest stable wgpu |
| CUDA driver version compatibility — cudarc bindings break on new CUDA toolkit or driver releases | 3 | 3 | 9 | Pin cudarc version range; document tested driver-toolkit combinations; CI gate on CUDA-capable runner detects breakage early | gpu-compute-agent | cudarc backend fails to compile on tested CUDA version |
