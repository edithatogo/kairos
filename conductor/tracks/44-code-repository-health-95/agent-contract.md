# 44 Code and Repository Health >= 9.5 - agent-contract.md

## health-agent

Owns the scorecard, validator, and remediation queue. Must keep the threshold at or above 9.5 unless release governance approves a stricter replacement.

## ci-agent

Owns workflow execution and status reporting.

## security-agent

Owns the supply-chain and security score evidence.

## release-agent

Owns final release gating and waiver approval.
