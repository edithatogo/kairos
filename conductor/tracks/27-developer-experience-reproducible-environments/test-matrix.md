## 2026-05-09 follow-up evidence

- `node scripts/dx/validate-toolchain-docs.mjs` initially failed because `scripts/bootstrap.sh` installed `just` through the versioned `spec` loop instead of the explicit `for tool in just` guard required by the validator.
- `scripts/bootstrap.sh` now installs `just` through `for tool in just; do cargo install "$tool" --locked || true; done` before the version-pinned cargo tool loop.
- `node scripts/dx/validate-toolchain-docs.mjs` passed after the bootstrap fix.
- `node scripts/dx/validate-docs-workflow.mjs` passed when rerun serially; an earlier parallel run hit a transient `127.0.0.1:41727` port collision.
- `scoop install just julia` installed `just` 1.50.0 and Julia 1.12.2.
- `just --version` returned `just 1.50.0`.
- `just --list` passed and listed the expected repo recipes.
- `just toolchain-docs` passed outside the sandbox.
- `just docs-smoke` passed outside the sandbox.
- `just docs-build` passed outside the sandbox.
- `just validate-conductor` passed outside the sandbox, including Conductor setup validation, phase gates, non-strict git closeout, and the Rust workspace tests invoked by the setup validator.

## 2026-05-10 follow-up evidence

- `just docs-bootstrap` passed outside the sandbox.
- `just validate-tracks21-27` passed outside the sandbox.
- `just dev-setup` initially exposed a Windows linker-path issue when raw `cargo install` ran under Git Bash with the default MSVC Rust toolchain and resolved `link` to Git's `usr/bin/link.exe`.
- `just dev-setup` now calls `pwsh -NoProfile -File scripts/bootstrap.ps1 -SkipPython -SkipNpm`.
- `scripts/bootstrap.ps1` now uses `rustup run stable-x86_64-pc-windows-gnu cargo install` for optional cargo installs when that toolchain is available.
- `just dev-setup` passed outside the sandbox after installing or confirming `cargo-nextest`, `cargo-vet`, `cargo-deny`, `cargo-audit`, and `cargo-llvm-cov`.
- `just dev-validate` passed outside the sandbox and confirmed Julia 1.12.2 plus `just` 1.50.0 are visible through the local toolchain.
