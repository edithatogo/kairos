## GitHub Pages finding

The live GitHub Pages Starlight routes are valid, but older custom static-site
routes such as `/kairos/docs/README.html` were not being generated by the
current Astro/Starlight build. That made legacy public links return 404 even
though the source documents still existed.

The docs build now runs a post-build compatibility generator that writes:

- legacy manifest-backed HTML pages under `website/build/`;
- `website/build/docs-index.json`;
- `website/build/robots.txt`;
- `website/build/sitemap.xml`.

The compatibility pages redirect readers to the canonical repository source
documents and link back to the Starlight documentation home.
