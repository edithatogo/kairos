## Exact new child cases: seven

These are additional `CaseSpec.name` values sent to the existing `restore_child_entrypoint`; they do not rename or count as any inherited child.

1. `portable-v4-handoff-moving` — capture a real in-flight routed carrier after its accepted Start dispatch; restore, then compare full Flow and transit suffix through arrival.
2. `portable-v4-handoff-paused-retained` — Pause while the original progress event remains LIVE; capture/restore that paused cut, then compare Pause/Resume suffix.
3. `portable-v4-handoff-paused-consumed` — Pause while the original progress event is LIVE, then actually advance the paused Flow until that stale original progress event is consumed as a no-op. Capture/restore only after consumption, Resume, and compare the suffix; do not substitute “progress first, then Pause.”
4. `portable-v4-handoff-arrived-unadmitted` — capture a committed Domain-arrival cut before Submit; restore the Arrived Handoff with no request, then submit/complete the real service on each runtime and compare.
5. `portable-v4-handoff-frontier-resume-live-domain` — schedule Resume at the actual final frontier before an older LIVE Domain event; compare the committed Resume arrival and prove the stale Domain event is a full-state no-op in both processes.
6. `portable-v4-handoff-admitted-completion` — capture after the real same-service Submit is already bound; restore the request binding, verify both arrival observers suppress, then compare actual grant/completion and progress.
7. `portable-v4-handoff-stable-key-generation-ties` — combine an actual Handoff context with real StableKey waiters, terminal retained keys, removed resource and reused generational identity; prove child event/order suffix parity and preserved keyed metadata.

Keep the existing 26 raw child cases, four decoded V3 trace proofs and 19 literal goldens byte-for-byte and with their original names. Add a dedicated suite test that iterates only these seven names; leave the existing legacy and V3 case arrays untouched.
