# C4.4 supplemental statistical diagnostics v1

Owner21 (private metric/cohort kernels),04 (sidecar manifest),12 (independent readback). This completes explicit C4 requirements for tie counts and source-derived coverage warnings. It does not change calibration-v1 logical/physical schemas, event_log.v1, public APIs, metric values, selection rules, units, seed contracts, or establish clinical/inferential acceptance.

## Exact tie semantics

Private MetricResult and GroupMetric retain nullable reference_tie_count and simulation_tie_count. Each is the number of selected non-null point observations minus the number of distinct exact numerical supports within that same side. Count multiplicity beyond the first support occurrence, not the number of tied support groups or cross-cohort coincidences. Compare exact reduced rational supports after existing preprocessing/sorting; equivalent forms (1/2,0.5) are identical. Weighted metrics retain all selected point observations, including zero-weight points, consistently with existing sample counts; tie counts are observational diagnostics, not effective sample size. No binary64 tie classification.

Empty or insufficient populations with valid parsed supports have exact counts (empty side0). Invalid or unverified results have null tie counts; never claim zero ties from rejected input. Existing Invalid overflow/precision behavior stays intact. Tie counting must not add arithmetic that rejects an otherwise supported metric or change reduction order/results.

## Derived coverage warnings

GroupMetric carries sorted unique coverage_warnings derived from its actual selected-cohort diagnostics and outcomes, not caller-provided warning strings or fixture expected values. Exact labels:

- censored_observations_present if either diagnostic censored count is positive;
- excluded_observations_present if either declared/window exclusion count is positive;
- failed_outcomes_present if either failed count is positive;
- infeasible_outcomes_present if either infeasible count is positive;
- missing_outcomes_present if either missing count is positive;
- tied_observations_present if either non-null tie count is positive;
- uncensored_subset_no_survival_correction if any actual raw row in that group has Outcome::Censored (excluded by the existing Point selection), even when no computable distance remains.

Independent flags overlap. Do not assert that an infeasible diagnostic necessarily excludes a point. Warnings are descriptive method/coverage limitations, not objective penalties or inferential validity. Empty groups have no invented warning. Raw attempts in invalid/unverified groups still produce truthful coverage warnings, but ties remain unknown/null. Existing uncertainty remains null; no p-value is introduced.

## Manifest extension

Output and c43.join_manifest.v1 gain metric_group_diagnostics as a canonical group-ordered list. One entry per declared actual distribution group, including declared empty groups, contains group, status, reference_count, simulation_count, reference_tie_count, simulation_tie_count, coverage_warnings. Raw metric records remain complete and hashed; source clock/window/Point selection is unchanged. Paired residual summaries keep their separate group_summaries and denominator semantics. Preserve original calibration Arrow records exactly; this supplement is the transport for diagnostics absent from the frozen calibration_metric.v1 schema.

Independent readers reconstruct exact selected supports from retained side-tagged raw records and source manifest, reconcile eligible/tie counts/status and warnings, and reject forged or missing required diagnostics. A dedicated strict mode may require the supplement while historical C4.3 artifacts remain readable under their original contract. Bind execution head, actual toolchain, source/input/output hashes. Validate current1.99 and optional floor1.88; default1.76 compatibility and exact-head hosted native/Arrow gates remain required.

## Required behavioral evidence

Tied/untied, same-support across sides, rational-equivalent forms, weighted zero-weight ties, unequal/empty/insufficient, invalid/unverified null diagnostics, raw overlapping flags, censored-outcome coverage, source-window exclusions, no-data empty groups, permutation invariance, and immutable logical Arrow/event schemas. Retain a mutation that changes actual tie counts/warnings and prove independent rejection. Review analytic W1=1/KS=.5 and frozen tail/fractional cases/count walkthrough separately.
