# Arrow/Parquet version and MSRV review package — 2026-10-02

**Disposition:** no dependency added. The existing owner-approved D1.2/ADR-0002
direction selects Arrow/Parquet `60.0.0` as a dated candidate only for a
separately reviewed package with candidate Rust floor `1.88`; existing workspace
packages retain Rust `1.76`. This C0.3 memo records that versioned handoff. Track
04 schema/interoperability agreement and actual package/Track 25/30 review of the
resolved graph remain required before C1 adds dependencies.

## Evidence checked

Kairos workspace `Cargo.toml` declares Rust `1.76`. The official Arrow Rust
54.3.1 tagged workspace manifest declares version 54.3.1, edition 2021,
`rust-version = 1.70`, Apache-2.0, and aligned `arrow`/`parquet` workspace crate
versions. Crates.io registry metadata on 2026-10-02 also reports both 54.3.1
crates with Rust 1.70 and Apache-2.0. See the [tagged workspace manifest](https://github.com/apache/arrow-rs/blob/54.3.1/Cargo.toml).

For comparison, the official 55.2.0 tagged manifest declares Rust 1.81 and
Apache-2.0 ([manifest](https://github.com/apache/arrow-rs/blob/55.2.0/Cargo.toml));
crates.io metadata reports arrow/parquet 56.2.1 at Rust 1.84, 57.3.1–59.3.0 at
Rust 1.85, and 60.0.0 at Rust 1.88. The Arrow 60 release notice separately
confirms its MSRV increase. Those versions do not meet the current 1.76 gate.
This comparison is snapshot-specific; recheck registry metadata and tags at
implementation time.

The 54.3.1 tagged `arrow/Cargo.toml` offers the `ipc` feature; default features
also enable CSV and JSON. The tagged `parquet/Cargo.toml` offers the `arrow`
feature that enables Arrow arrays/schema/select/IPC APIs; its defaults also
include compression codecs and other optional features. A minimal trial should
start with `default-features = false`, Arrow `ipc`, and Parquet `arrow`, then add
only formats/codecs justified by C1 fixtures. See [Arrow features](https://github.com/apache/arrow-rs/blob/54.3.1/arrow/Cargo.toml)
and [Parquet features](https://github.com/apache/arrow-rs/blob/54.3.1/parquet/Cargo.toml).

## Required owner review and trial

No refreshed owner decision is needed to repeat the already approved policy
direction, but the actual future package graph must still pass its separate
review gates. A C1 packet should:

1. Add `arrow = 60.0.0` and `parquet = 60.0.0` only to the separately reviewed
   optional IO package, with candidate floor Rust 1.88; never add this graph to
   the existing Rust 1.76 workspace feature set.
2. Agree C0.2 schema mapping and physical representation with Track 04, then
   review exact features, every resolved transitive crate MSRV, licences and
   security advisories with Tracks 25/30.
3. Record a lockfile and package `rust-version` decision, run minimal-feature
   IPC/Parquet interop fixtures under Rust 1.88 and current stable, and retain
   the existing workspace Rust 1.76 default-feature lane unchanged.
4. Re-evaluate the candidate against the registry and compatibility policy
   immediately before implementation; this dated C0.3 record does not say 60.0.0
   remains current or approved forever.

No release-time “latest” claim is made. The existence of a release whose own
manifest says 1.70 is not proof that a 1.76 feature-minimal resolved graph passes.
The package boundary and candidate floor were already approved in D1.2/ADR-0002;
that approval is cited, not re-created here. No Cargo manifest/lockfile changed
and no dependency was added to Kairos. The isolated 54.3.1 alternate trial is
reported in the C0.3 source ledger and is not the selected policy direction.
