# C4.1 fixture contract clarifications v1

Track 21 coordinator clarification after independent statistical review, before
fixture acceptance. This supplements c4.1-fixture-contract-v1.md without changing
its report layout, production APIs or C0.2 sidecar semantics.

- The additive equations describe **exclusive primary dispositions of these
  synthetic fixtures only**. Record primary partitions under
  diagnostic.primary_dispositions. They are not general residual metric counts.
  Generic failed/infeasible/excluded/censored diagnostic counts may overlap;
  diagnostic.overlap_counts is expressly non-additive. Include a valid point
  prediction also flagged infeasible to prove it is not subtracted twice.
- Aggregate primary censored covers left/right/interval censored, with exact
  subtype counts retained. A right-censored-only fixture can specialize this.
  Cohort=input; eligible=cohort-excluded; eligible primary partitions sum once.
- Unpaired distribution fixtures report unmatched=0 and label it not applicable
  to an unpaired estimand. No claim of paired residual-summary qualification.
- Exact rational oracles preserve fractional/signed residual supports. They do
  not require exact binary64 supports unless the case explicitly tests candidate
  float-conversion preprocessing. The unsigned u128/common-origin rule applies
  to absolute event ticks only; the ONE common origin must not exceed any input
  tick, so those offsets are nonnegative. It does not restrict signed residuals.
- exact_offsets/rejected is the explicit tick-to-float preprocessing test status;
  ordinary rational support cases use not_applicable. Do not reject rational
  oracle values simply because their final float representation is approximate.
- Independent SciPy float cross-check uses the same frozen W1 absolute bound
  1e-12*max(1,scale_ticks) and KS_D bound 1e-12. These are synthetic numerical
  conformance bounds, with exact Fraction values authoritative, never clinical
  calibration acceptance thresholds.

This clarifies the older count equation's fixture-specific scope; the existing
calibration-residual-metric-seed-v1.md diagnostic overlap contract is preserved.
The prepared candidate gate remains expected red until C4.2 provides actual
runtime output. C-04 and C4.2–C4.4 remain open.
