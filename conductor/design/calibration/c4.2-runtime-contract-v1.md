# C4.2 private runtime contract v1

Coordinator-approved bounded implementation under accepted ADR-0005 placement and C0.2 residual/metric semantics. Owner 21; owner 12 test-only conformance adapter. Implements C4.2 only; no public Rust API, Arrow, scheduler, dependencies or seed changes. Private modules remain experimental; C4.3 encoding and C4.4/C-04 phase acceptance stay separate.

## Exact distance kernel

`src/metrics.rs` exposes only crate-private items. Frozen adapter entry:

```rust
pub(crate) fn compare(request: &MetricRequest<'_>) -> MetricResult;
pub(crate) struct MetricRequest<'a> {
    pub reference: &'a [Option<&'a str>],
    pub simulation: &'a [Option<&'a str>],
    pub reference_weights: Option<&'a [&'a str]>,
    pub simulation_weights: Option<&'a [&'a str]>,
    pub algorithm_version: &'a str,
    pub origin: Option<&'a str>,
    pub scale_ticks: &'a str,
}
pub(crate) enum MetricStatus { Computed, Empty, InsufficientData, Invalid }
pub(crate) enum Precision { NotApplicable, ExactOffsets, Rejected }
pub(crate) struct MetricResult {
    pub status: MetricStatus,
    pub w1: Option<f64>, pub ks_d: Option<f64>,
    pub reference_count: usize, pub simulation_count: usize,
    pub precision: Precision,
}
```

Support strings are declared unit values; optional origin makes them absolute unsigned u128 ticks. Decimal/rational parsing retains exact signed magnitude and positive denominator, with gcd normalization and checked u128 arithmetic; no rounded CDFs. All ties aggregate before right-continuous CDF gap. Equal counts or exact nonnegative rational weights normalize each side independently. W1 sum and KS maximum use checked exact rational arithmetic and convert only at final output; tick W1 divides by positive exact scale once. Common origin subtraction is checked before any float conversion; every tick offset must be exactly binary64-representable (bit length/trailing zeros), including full-u128 values. Rational magnitude/denominator and checked reduced intermediates are bounded to u128: representational overflow returns Invalid/null, never wraps, silently rounds or introduces a float fallback. Finite JSON output required. Record this bounded arithmetic limitation explicitly; no arbitrary-precision promise. Algorithm names consume empirical_equal.v1 and weighted_descriptive.v1. No KS inference/p-value.

Validate raw weight length and every raw weight before dropping aligned null supports or classifying empty. Zero-weight observations retain point counts. Nonempty populations require positive finite mass; unknown algorithm, malformed/nonfinite support/weight, negative/zero-total weight and incompatible scale produce invalid/null/zero metric counts. Nulls remain missing. Both eligible populations empty => Empty; one empty => InsufficientData. Valid origin input => ExactOffsets; origin/preprocessing errors => Rejected; ordinary invalid support cases => NotApplicable. Coverage metadata belongs to the adapter, not distance kernel.

## Paired residuals and fixed strata/windows

`src/residuals.rs` is private, with exact unsigned-u128 sign/magnitude point residuals: predicted minus observed, no signed-i128 cast. Pair REFERENCE observed endpoint rows against SIMULATION unclamped point predictions using the complete C0.2 logical tuple (study/dataset/scenario/schedule/replication/case/task/occurrence/endpoint/purpose/map/mapping), excluding candidate/run IDs. This is prediction error, not a difference of two candidate residuals. Duplicates or contradictory provenance/status inputs are invalid; unsupported provenance is unverified. Failure/censor/missing/infeasible outcomes retain explicit statuses and nullable values. Never clamp or impute. A valid point prediction may independently be infeasible or late.

Declare fixed endpoint, externally supplied strata and optional [start,end) window on observed/source selection time. Selection time is an explicit field distinct from predicted ticks and may be present for censored/missing rows; never substitute prediction for absent selection time. Reject invalid windows or mixed unit/endpoint/mapping/schedule cohorts. Explicit prespecified groups emit empty results. Records outside window/excluded by declared rule remain counted. Overlapping excluded/censored/missing/failed/infeasible diagnostics are independent, not additive. Unmatched counts include input records without an eligible valid numeric counterpart, once per side. Preserve all primary status-bearing rows in output.

Equal-weight summary semantics residual_summary.canonical_float.v1: signed mean (bias), MAE, RMSE over matched computed errors only; ascending logical key reduction, deterministic compensated float sums after exact sign/magnitude computation. Values are descriptive binary64 summaries, not exact ticks; flag approximation when u128 magnitudes lose exact float precision. Nonfinite reduction is invalid/null; no p-values/uncertainty. Individual residual signs/magnitudes always exact and output ticks are never modified. Both eligible point populations empty => Empty; no valid pairs with any point population => InsufficientData. All noncomputed statuses return null summaries. Explicit no pairing/provenance support => Unverified/null. Window/group counts and rows remain present on noncomputed output.
