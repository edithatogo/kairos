# C4.3 private Arrow output adapter — physical v1 ADR

Status: reviewed coordinator implementation contract, 5 October 2026. Owners
21/04/12; private experimental adapter only. Extends ADR-0005 with a private outer
IO adapter in calibration, behind empty-default ipc/parquet features. No public
Rust API, package upgrade, core dependency, event_log.v1 change or C-04 acceptance.

## Boundary and frozen layout

Consume C0 logical calibration-v1 at
conductor/research/c0.3-source-inputs-20261001/calibration-v1.schema.json unchanged.
The output schemas are separate from C1 trace physical-v2. Encode every required
logical residual/metric field, with exact ordered schema and metadata, never
infer a schema from rows. Preserve actual nulls. Admission validates status,
IDs, hashes, full u128, enums, counts and finite numeric values before encoding.
Reject unknown/missing fields and wrong JSON types, including bool-as-count.

Residual columns in C0 required-field order: record_type, schema_version,
dataset_id, scenario_id, run_id, candidate_id, case_key, task_key, occurrence,
endpoint, fidelity, observed_ticks, predicted_ticks, residual_status,
residual_sign, residual_magnitude, prediction_unclamped, anchor_role,
feasibility, censor_status, study_id, replication_id, seed_schedule_id,
seed_purpose, seed_map_ref, seed_contract_version, mapping_version,
parameter_hash, graph_hash, causal_ref. Utf8 unless: occurrence UInt32;
observed_ticks/predicted_ticks/residual_magnitude nullable FixedSizeBinary(16)
unsigned_u128_le, unit=1ns; prediction_unclamped Boolean. graph_hash and causal_ref
nullable Utf8. Computed sign/magnitude must equal checked predicted-observed.
Noncomputed signs undefined and magnitudes null; missing/censored observed null,
probe_failed predicted null. prediction_unclamped always true.

Metric columns in C0 required-field order, flattening window/provenance:
record_type, schema_version, metric, algorithm_version, endpoint, strata,
window_start_ticks, window_end_ticks, units, reference_count, simulation_count,
excluded_count, censored_count, missing_count, unmatched_count, failed_count,
infeasible_count, value, status, uncertainty, provenance_dataset_id,
provenance_run_id, provenance_mapping_version, provenance_seed_schedule_id,
provenance_seed_map_ref, provenance_seed_contract_version,
provenance_parameter_hash. Counts UInt64 checked from unsigned integers; window
FixedSizeBinary(16) required with unsigned_u128_le/unit=1ns. value nullable
Float64 finite only. strata Utf8 canonical JSON object (sorted keys recursively,
no whitespace); C0 permits arbitrary JSON-valued strata so this preserves that
open logical object without inventing a typed stratum vocabulary. uncertainty
nullable Utf8 reserved canonical JSON; nonnull uncertainty rejected until a
separate named method exists. Last four provenance fields nullable Utf8; others
Utf8 required. Noncomputed values null; W1 units from cohort, KS_D dimensionless;
seed map/schedule both present for attempted simulation or both null only for no
seeded attempts. Diagnostics overlap and are never summed as a denominator.
Paired summary emits three records: metric=paired_residual_summary with strata
containing statistic=bias/mae/rmse, algorithm residual_summary.canonical_float.v1.

Schema metadata: format=kairoecs.calibration.output, physical_version=1,
logical_schema=calibration-v1, record_type=<logical stream>, byte_order=little.
Tick field metadata encoding=unsigned_u128_le, unit=1ns; strata metadata
encoding=canonical_json_object. Exact equality includes all metadata/nullability.

## Runtime and joins

A separate private runtime adapter calls actual C4.2 summarize/compare_groups;
never supplies expected/oracle values as actual outputs. Bind externally declared
run provenance (study/dataset/scenario/candidate/replication/schedule/map/mapping,
parameter hash/fidelity) to each emitted row. Fail before publication on mismatch,
missing/duplicate run or event join, ambiguous duplicate pair or invalid cohort.
Use existing kairo_ecs_arrow::EventLogRecord, its validate() and event_id handle.
causal_ref when present has explicit canonical event:<index>:<generation> form;
resolve under (run_id,event_id), never guess source_event_key equivalence. Null
causal_ref is permitted and means no asserted event link. Run records remain
external runner provenance, not a new runner implementation. Do not rewrite
run IDs out of sidecar provenance because pairing excludes them.

Emit a residual for every logical pair, including unmatched/missing/censored/
failed/infeasible pairs. Exclusion diagnostics remain in summary metrics. Valid point pairs retain exact
descriptive residuals even outside the summary cohort; exclusion does not invent
a missing/censored status. Nonpoint pairs have no manufactured residual.
An observed point lacking a simulation is probe_failed; simulation lacking an
observation is missing_observed. Keep supporting raw rows in adapter result for
excluded/invalid source diagnostics; invalid batches fail sidecar publication,
never silently omit them. A valid late/infeasible point may remain computed with
feasibility=infeasible under C4.2 eligibility. Preserve full endpoint pairing key.
Window is explicit half-open [start,end), source clock only. Fixed groups come
from external spec. No implicit all-time or candidate-cohort mixing.

## Determinism and qualification

Runtime sorts/reduces by C4.2 canonical keys. Encoder sorts residuals by full
12-field logical pair tuple followed by candidate/run; metrics by endpoint,
canonical strata, window, provenance, metric and algorithm. Reject duplicate
logical output keys. Logical canonical records and metric bits must agree after
input permutation and across IPC batch/Parquet row-group sizes; encoded physical
bytes may differ with framing. Never require byte equality across formats.
Actual IPC file/stream and Parquet use existing bounded arrow-io APIs and caller
IoLimits. Empty outputs retain schema. Readback independently verifies exact
schema/type/metadata, nulls, units, u128 0/MAX, counts and run/event joins using
PyArrow25.0.1 plus unchanged C0 JSON Schema. Test negative statuses, joins, bad
hash/unit/type, mutation, duplicate records, schema mismatch and unsupported
uncertainty. Feature none/ipc/parquet/both at current Rust1.99 and floor1.88;
legacy event schema/fingerprint and smoke bytes unchanged. No Python runtime
dependency; Python is an independent qualification reader only. Existing Arrow
allocation/untrusted input limitations remain. C4.4 and C-04 stay open.

## Coordinator review addenda (before integrated qualification)

C0 has no excluded residual status: retain exact descriptive point differences
independently of summary eligibility. Manifest eligible means contributing valid
pair; excluded means declared source/window exclusion, not the complement of
eligible. In-window missing/censored/failed/unmatched rows are not automatically
excluded. Every raw residual Row/Evidence and metric cohort Row is retained with
side, key, group, source clock, value/weight, flags and provenance. Separate
canonical hashes/counts identify residual and metric source collections. Hash
compact UTF-8 sorted-key JSON arrays, sorting raw records by canonical JSON text.

Paired bias/MAE/RMSE reference_count and simulation_count both equal the number
of matched pairs actually used; manifest group summaries retain C4.2 eligible
reference/simulation populations, matched/unmatched/raw counts and approximation
flags. Diagnostic counts remain independent and may overlap. No kernel change.
Structural metric contradictions (duplicate key, Point/value mismatch, unknown
group, ambiguous strata) fail publication retaining sources. Kernel numerical/
precision rejection may emit invalid/null metrics with their raw diagnostics.
This private adapter admits empirical_equal.v1, scale_ticks=1, nanosecond only;
unit conversion/weighted output integration requires a separately reviewed scope.

Output causal_ref prefers the simulation reference, falling back to reference
side evidence; both source links remain in raw records. Probe/feasibility prefer
simulation evidence, censor category comes from the actual censor/missing row,
and conflicting nonnull graph hashes fail. Null links assert no event relation.

Independent review caught and corrected ordering, nested-field admission, physical
nullability/metadata, retained source coverage, exclusion meaning and denominator
ambiguities. Worker packets bind the earlier contract hash; these addenda and
final integrated source/checks supersede it for task acceptance.
