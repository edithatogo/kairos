# C4.2 cohort and window contract v1

Coordinator-reviewed extension of c4.2-runtime-contract-v1. Private Rust types only, no wire/public API or inference. src/metric_cohorts.rs delegates every W1/KS computation to metrics::compare.

Reference and simulation input share an explicit cohort identity (dataset, endpoint, unit, mapping version, seed schedule and seed map). Mixed identities are invalid. Source-evidence verification is an explicit precondition: unverified inputs produce Unverified/null, never computed. No patient data, source-derived strata or inferred provenance.

Record logical keys are unique per side, fixed group names are declared before comparison, and all fixed groups emit a result including empty groups. Windows are optional half-open [start,end) over explicit observed/source selection_time, not predicted or support value. Invalid window bounds, duplicate keys/groups, unknown groups or contradictory primary outcomes fail closed. Missing selection time is excluded under source_window.v1 and counted missing; it is never supplied from prediction.

Outcome is Point, Missing, Censored, Failed or Infeasible, with Point requiring a value and other outcomes requiring null. Independent diagnostic flags may overlap point counts or one another; valid point predictions flagged infeasible remain points unless the explicit exclusion rule excludes them. Count raw instances, excluded instances, censor/missing/failure/infeasibility diagnostics separately; W1/KS unpaired unmatched is always zero. Numeric contributing point counts come from kernel results, not raw attempts; whole-comparison invalid results have zero numeric counts. Keep raw and exclusion diagnostics even when no metric exists.

Sort contributing records by stable logical key before handing supports/weights to exact kernel; kernel sorts numeric support and aggregates ties. Equal-weight requests reject explicit weights; weighted requests require weight for each input point. Non-point rows have no implicit weight mass. Unit, scale, algorithm and optional exact common origin are fixed in spec. Coverage counts and warnings are adapter semantics, not public calibration_metric.v1 serialization. No survival adjustment, p-values or uncertainty. Independent permutation/window/identity/invalid/coverage tests and actual-source integration review gate acceptance.
